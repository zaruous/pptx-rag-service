# 기능 요구사항

| ID | 제목 | 설명 | 주요 사용자 | 선행조건 | 결과 | 우선순위 |
|---|---|---|---|---|---|---|
| `FR-01` | PPTX 업로드 | 사용자가 PPTX를 업로드할 수 있어야 한다 | 운영자 | 로그인, 권한 보유 | 문서/버전 생성 | 높음 |
| `FR-02` | 슬라이드 파싱 | 시스템이 슬라이드별 텍스트와 요소를 추출해야 한다 | 시스템 | 업로드 완료 | slide 메타 생성 | 높음 |
| `FR-03` | OCR 보강 | 이미지 기반 텍스트를 선택적으로 추출해야 한다 | 시스템 | OCR 옵션 활성화 | OCR chunk 생성 | 중간 |
| `FR-04` | 슬라이드 요약 생성 | 슬라이드 맥락 요약을 생성해야 한다 | 시스템 | 추출 텍스트 확보 | summary chunk 생성 | 높음 |
| `FR-05` | 워크플로우 구조 추출 | 프로세스형 슬라이드에서 단계, 담당자, 연결, 예외를 추출해야 한다 | 시스템 | 프로세스 슬라이드 판별 | workflow graph 생성 | 높음 |
| `FR-06` | 벡터 적재 | 모든 검색용 chunk를 Chroma에 적재해야 한다 | 시스템 | 임베딩 가능 | 인덱싱 완료 | 높음 |
| `FR-07` | 질의 응답 | 사용자의 질문에 답변을 생성해야 한다 | 일반 사용자 | 인덱싱된 문서 존재 | 답변 반환 | 높음 |
| `FR-08` | 페이지 근거 표시 | 답변과 함께 문서명과 슬라이드 번호를 반환해야 한다 | 일반 사용자 | 검색 결과 존재 | evidences 반환 | 높음 |
| `FR-09` | 프로세스 질의 대응 | 단계 순서, 담당 부서, 분기 조건 질의에 답할 수 있어야 한다 | 일반 사용자 | workflow graph 존재 | workflow evidence 반환 | 높음 |
| `FR-10` | 질의 유형 분류 | workflow, 수치, 비교, 개요 질의를 구분해야 한다 | 시스템 | 질문 입력 | retrieval plan 생성 | 높음 |
| `FR-11` | no-answer 처리 | 근거가 부족하면 답변을 보류할 수 있어야 한다 | 시스템 | 검색 점수 부족 | no-answer 반환 | 높음 |
| `FR-12` | 저신뢰 검수 큐 | low-confidence 슬라이드와 workflow를 검수 대상으로 분류해야 한다 | 운영자 | 추출 완료 | review queue 적재 | 중간 |
| `FR-13` | 검수 결정 반영 | 승인/반려/재처리 요청이 retrieval과 재처리에 반영되어야 한다 | 운영자 | review candidate 존재 | 상태 반영 | 중간 |
| `FR-14` | 재처리 | 실패 또는 정책 변경 시 재처리를 지원해야 한다 | 운영자 | 문서 존재 | 신규 job 생성 | 높음 |
| `FR-15` | 버전 관리 | 동일 문서의 업로드 버전을 관리해야 한다 | 운영자 | 기존 문서 존재 | 버전 이력 유지 | 중간 |
| `FR-16` | 검색 범위 제한 | workspace 또는 문서 필터 검색을 지원해야 한다 | 일반 사용자 | 권한 범위 존재 | 범위 내 검색 | 높음 |
| `FR-17` | 질의 로그 | 질문, 근거, 응답 시간을 기록해야 한다 | 운영자 | 질의 실행 | 로그 적재 | 중간 |
| `FR-18` | 삭제 및 비활성화 | 문서 제거 또는 검색 제외를 지원해야 한다 | 관리자 | 대상 문서 존재 | 검색 제외 | 중간 |
