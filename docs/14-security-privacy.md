# 보안 및 개인정보 체크리스트

## 인증/인가

- workspace 단위 접근 제어 필요
- 관리자 API는 일반 질의 API와 분리 권장

## 민감정보 처리

- PPTX 내부에 개인정보나 대외비가 포함될 수 있으므로 원문 저장 정책 명확화 필요
- 질의 로그에는 필요 이상으로 원문 chunk를 남기지 않는 구성이 안전하다

## 저장소 보안

- 파일 저장소 경로 접근 제한
- Chroma 접근 네트워크 제한
- DB 계정 최소 권한

## 로그 경계

- 업로드 파일 전체 내용을 애플리케이션 로그에 남기지 않는다
- 예외 로그에는 파일 경로와 내부 ID 위주로 남긴다

## 삭제 및 보존

- 문서 삭제 요청 시 파일, 썸네일, 벡터, 메타데이터 정리 범위를 명확히 정의해야 한다
- 보존 기간이 있는 경우 soft delete 기간을 정책화한다

## 남은 보안 이슈

- 외부 임베딩 API 사용 시 데이터 외부 전송 여부 검토
- OCR 외부 서비스 사용 시 문서 반출 정책 검토
