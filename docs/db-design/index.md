# DB 설계 인덱스

## 목적

Chroma 외부에서 관리해야 하는 운영 메타데이터와 조회 모델을 정의한다.

## 설계 원칙

- 문서 상태 관리는 RDB에서 수행한다.
- 벡터는 Chroma에 저장하지만, slide/chunk의 기준 메타정보는 RDB에도 최소한 유지한다.
- 삭제, 재처리, 감사 추적을 위해 버전과 잡을 분리한다.

## 문서 목록

- `core-entities.md`: 핵심 테이블 설계

## 공통 컬럼 규칙

- 모든 주요 테이블에 `created_at`, `updated_at` 포함
- 삭제 대신 `is_active` 또는 `deleted_at` 우선 고려
- 외부 노출 ID와 내부 증가 ID를 분리할 수 있음
