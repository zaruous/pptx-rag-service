# Document Detail

## 화면명

문서 상세 및 슬라이드 인덱싱 상태

## 목표

업로드된 PPTX의 버전, 슬라이드별 추출 결과, chunk 상태를 확인한다.

## 주요 사용자

- 운영자
- 시스템 관리자

## 진입 경로

- 업로드 목록에서 문서 선택

## 주요 컴포넌트

- 문서 메타정보 카드
- 버전 이력 탭
- 슬라이드 목록
- 썸네일 미리보기
- 추출 텍스트/OCR/summary 확인 패널

## 입력

- document ID
- version ID

## 출력

- 슬라이드별 추출 상태
- chunk 수
- Chroma 적재 여부

## 주요 액션

- 버전 전환
- 슬라이드 재처리
- 문서 삭제 또는 비활성화

## ASCII Wireframe

```text
+----------------------------------------------------------------------------------+
| Document Detail: annual-report.pptx                           [비활성화] [재처리] |
+----------------------------------------------------------------------------------+
| Meta Card                    | Version History                                   |
|-----------------------------|----------------------------------------------------|
| 문서 상태: ACTIVE            | v3 DONE       v2 DONE       v1 FAILED              |
| 현재 버전: v3               | [선택]                                           |
| 해시 / 업로드자 / 시각       |                                                    |
+----------------------------------------------------------------------------------+
| Slides List                 | Slide Preview / Extracted Data                     |
|-----------------------------|----------------------------------------------------|
| 1  표지                     | [썸네일]                                           |
| 2  개요                     | Title: ...                                         |
| 3  출하 프로세스            | Summary: ...                                       |
| 4  KPI 비교                 | Raw Text / OCR / Facts / Workflow Tabs             |
| ...                         |                                                    |
| [슬라이드 재처리]            | [Chunk 상태] [Chroma 적재 여부]                    |
+----------------------------------------------------------------------------------+
```

영역 메모:
- 좌측은 슬라이드 탐색, 우측은 선택 슬라이드의 추출 결과 검증에 집중한다.
- `Summary / Facts / Workflow`를 같은 자리에서 비교할 수 있어야 검수 효율이 높다.

## 검증 규칙

- 삭제는 인덱스 정리 정책 확인 후 가능

## 빈 상태

- 슬라이드 정보 미생성

## 오류 상태

- 썸네일 생성 실패
- Chroma 조회 실패

## 권한

- 운영자 이상
