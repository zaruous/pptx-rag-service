# Query Console

## 화면명

질의 및 근거 슬라이드 확인

## 목표

사용자가 질문을 입력하고 관련 PPTX, 슬라이드 번호, 스니펫을 함께 확인한다.

## 주요 사용자

- 일반 사용자
- 운영자

## 진입 경로

- 검색/질의 메뉴

## 주요 컴포넌트

- 질의 입력창
- workspace/document 필터
- 답변 영역
- 근거 슬라이드 목록
- 슬라이드 썸네일/미리보기

## 입력

- 자연어 질문
- 검색 범위

## 출력

- 답변
- 근거 문서명
- 슬라이드 번호
- 스니펫

## 주요 액션

- 질문 제출
- 근거 슬라이드 열기
- 특정 문서만 다시 검색

## 검증 규칙

- 너무 짧은 질문 제한
- workspace 권한 범위 밖 문서 접근 금지

## 빈 상태

- 아직 질문 없음

## 오류 상태

- 검색 결과 없음
- 모델 응답 생성 실패

## 권한

- 조회 권한이 있는 사용자

## 추적 이벤트

- `query_submitted`
- `evidence_slide_clicked`
