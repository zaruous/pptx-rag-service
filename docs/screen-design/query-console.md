# Query Console

## 화면명

질의 및 근거 슬라이드 확인

## 목표

사용자가 질문을 입력하고 관련 PPTX, 슬라이드 번호, 스니펫을 함께 확인한다.

## 주요 사용자

- 일반 사용자
- 운영자

## 진입 경로

- 검색/질의 메뉴

## 주요 컴포넌트

- 질의 입력창
- workspace/document 필터
- 답변 영역
- 근거 슬라이드 목록
- 슬라이드 썸네일/미리보기

## 입력

- 자연어 질문
- 검색 범위

## 출력

- 답변
- 근거 문서명
- 슬라이드 번호
- 스니펫

## 주요 액션

- 질문 제출
- 근거 슬라이드 열기
- 특정 문서만 다시 검색

## ASCII Wireframe

```text
+----------------------------------------------------------------------------------+
| Query Console                                                                    |
+----------------------------------------------------------------------------------+
| Search Bar                                                                       |
| [질문을 입력하세요.........................................................] [질문] |
| [Workspace ▼] [Document Filter ▼] [No-Answer 허용 □]                            |
+----------------------------------------------------------------------------------+
| Answer Panel                                                                     |
|----------------------------------------------------------------------------------|
| 답변: 2024년 성장률이 가장 높은 사업 부문은 플랫폼 사업으로 보인다.              |
+----------------------------------------------------------------------------------+
| Evidences                                   | Slide Preview                       |
|--------------------------------------------|-------------------------------------|
| 1. annual-report.pptx / 12번 슬라이드       | [선택된 슬라이드 썸네일]            |
|    플랫폼 사업의 성장률이 35%로 가장 높음   | 문서명 / 슬라이드 번호              |
|    score: 0.93  [열기]                      | summary / snippet                   |
|--------------------------------------------|-------------------------------------|
| 2. business-review.pptx / 7번 슬라이드      |                                     |
|    ...                                      |                                     |
+----------------------------------------------------------------------------------+
```

영역 메모:
- 답변과 근거를 분리해, 사용자가 먼저 답을 보고 바로 옆에서 근거를 검증할 수 있게 한다.
- Evidence 클릭 시 우측 미리보기만 교체되는 구조가 탐색 비용이 낮다.

## 검증 규칙

- 너무 짧은 질문 제한
- workspace 권한 범위 밖 문서 접근 금지

## 빈 상태

- 아직 질문 없음

## 오류 상태

- 검색 결과 없음
- 모델 응답 생성 실패

## 권한

- 조회 권한이 있는 사용자
