# 화면 설계 인덱스

## 목적

이 폴더는 서버 중심 시스템을 운영하기 위한 최소 화면 구성을 정의한다.

## 화면 목록

- `upload-admin.md`: PPTX 업로드 및 인덱싱 실행
- `document-detail.md`: 문서 버전, 슬라이드, 처리 상태 확인
- `query-console.md`: 질문 입력과 근거 슬라이드 확인
- `review-queue.md`: 저신뢰 슬라이드/워크플로우 검수

## 비고

- 실제 UI 프레임워크는 범위 밖이다.
- 운영 효율을 위해 관리자 화면과 일반 질의 화면을 분리하는 구성이 적절하다.
